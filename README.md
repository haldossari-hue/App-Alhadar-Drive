# الهدار درايف — النسخة المستقلة

تطبيق توصيل محلي لمدينة الهدار (محافظة الأفلاج): عميل، سائق، إدارة. خادم حقيقي وقاعدة بيانات مستقلة، ولا يحتاج أي مستخدم حساب Claude.
التطبيق **PWA**: رابط ويب يفتح مباشرة، ويقدر المستخدم يضيفه للشاشة الرئيسية كتطبيق ويستقبل إشعارات.

## التشغيل محلياً

```bash
npm install
npm run import:artifact -- data/import   # (اختياري) استيراد بيانات النسخة القديمة
npm start                                 # http://localhost:3000
```

- رمز الإدارة الافتراضي `1234` في القاعدة الجديدة. إذا استوردت البيانات القديمة، يشتغل رمز الإدارة القديم نفسه.
- في وضع التطوير يظهر رمز التحقق (SMS) على الشاشة وفي سجل الخادم، بدل ما يُرسل فعلاً.

## الاختبارات

```bash
npm test            # 23 اختبار: منطق التسعير + كل تدفقات الـ API
npm run test:e2e    # 6 اختبارات واجهة في متصفح حقيقي (عميل + سائق + إدارة بنفس الوقت)
```

تغطي: التسجيل برمز SMS، السلة من متجرين وطلبين A/B، حد المتجرين، البيع بالوزن، الكوبونات (أكبر خصم، مرة لكل عميل، التصنيفات، الحد الأدنى، الانتهاء)، برنامج الولاء واسترجاع التوصيلة عند الإلغاء، الطلب الخاص وتسعيره، الحوالة وإثباتها الإلزامي، الدفع الإلكتروني (نجاح/فشل)، التدفق المباشر للسائق ومنع استلام الطلب نفسه من سائقين، المحادثة وصلاحياتها، تتبع الموقع، استرجاع رمز الإدارة، الصلاحيات، وترحيل الرموز القديمة.
شغّلها قبل كل نشر.

## البنية

| الجزء | التقنية |
|---|---|
| الخادم | Node.js 22 + Fastify |
| قاعدة البيانات | SQLite (مدمجة بـ Node، ملف واحد `data/alhadar.db`، وتكفي مدينة كاملة بسهولة) |
| التحديث اللحظي | Server-Sent Events: طلبات، حالات، محادثة، موقع السائق |
| الواجهة | PWA بدون أطر عمل (نفس تصميم النسخة الأصلية وهويتها بالكامل) |
| الإشعارات | Web Push (VAPID) عبر Service Worker |
| الخرائط | Leaflet + OpenStreetMap (بدون مفتاح API) |

```
src/
  app.js            كل مسارات الـ API والصلاحيات
  orders.js         إنشاء الطلبات، تدفق الحالات، الولاء، الاسترجاع، الإشعارات
  domain/pricing.js منطق السلة والكوبونات والرسوم (دوال صافية ومختبرة)
  repo.js / db.js   القاعدة والجداول
  auth.js           تشفير الرموز (scrypt) والجلسات الموقعة
  services/         SMS، Push، بوابة الدفع، البث اللحظي
public/             الواجهة (PWA)
  shared/constants.js  ثوابت مشتركة بين الخادم والواجهة (التصنيفات، الحالات، الأوزان)
scripts/            الاستيراد، النسخ الاحتياطي، إعادة ضبط رمز الإدارة، الأيقونات
```

**قواعد مهمة مطبّقة في الخادم (مو بالمتصفح):** كل الأسعار والخصومات والرسوم تُحسب في الخادم من جديد عند إنشاء الطلب، فما يقدر أحد يعدّل السعر من المتصفح. استلام السائق للطلب يتم داخل معاملة حصرية، فسائقان ما يقدرون يستلمون الطلب نفسه. السائق ما يشوف اسم العميل ولا جواله ولا عنوانه إلا بعد ما يستلم الطلب. إثباتات التحويل وصور الطلبات الخاصة ملفات خاصة تُفتح برابط موقّع ومؤقت فقط.

## اللي تحتاجه من جهتك للإطلاق

1. **خادم VPS** (أي مزود، 1 نواة و1GB رام تكفي للبداية)، و**نطاق** (مثل `alhadar.sa`) بسجل A يشير للخادم.
2. **Moyasar**: حساب تاجر مربوط بالسجل التجاري، ثم `MOYASAR_SECRET_KEY`. من لوحة Moyasar فعّل Apple Pay وSTC Pay، وأضف رابط الـ webhook: `https://نطاقك/api/payments/webhook`.
3. **SMS**: حساب في Unifonic أو Taqnyat، مع **اسم مرسل معتمد** من هيئة الاتصالات (يأخذ أيام). راجع صيغة الـ API مع وثائق المزوّد وقت التفعيل، لأنها ممكن تتغير.
4. انسخ `.env.example` إلى `.env` وعبّئه، ولازم يكون فيه `APP_SECRET` عشوائي: `openssl rand -hex 32`.

## النشر

```bash
# على الخادم
git clone <المستودع> && cd alhadar-drive
cp .env.example .env && nano .env          # عبّئ القيم
nano deploy/Caddyfile                       # اكتب نطاقك
mkdir -p data && cp -r <مجلد_التصدير> data/import
docker compose run --rm app node scripts/import-artifact-export.js data/import
docker compose up -d --build
```

Caddy يطلع شهادة HTTPS تلقائياً. الـ HTTPS **إلزامي**، لأن الإشعارات وتحديد الموقع والدفع ما تشتغل بدونه.

**النسخ الاحتياطي:** شغّل `scripts/backup.sh` يومياً عبر cron. ينسخ القاعدة والملفات بأمان أثناء التشغيل ويحذف النسخ الأقدم من 30 يوماً. انسخ مجلد `backups/` لمكان خارج الخادم.

**نسيت رمز الإدارة ورمز الاسترجاع معاً؟** على الخادم: `node scripts/reset-admin-pin.js 123456`

## نقل البيانات من النسخة القديمة

`scripts/import-artifact-export.js` ينقل: المتاجر العشرين وكل منتجاتها (407، منها 66 مسعّرة)، الأحياء، رسوم التوصيل، بيانات الحوالة، رقم الدعم، إعدادات الولاء، الكوبونات، السائقين، ورمز الإدارة. ويقدر ينقل العملاء والطلبات القديمة كذلك لو صدّرتها.

- **صور المنتجات** المرفوعة على منصة Claude ما تنتقل تلقائياً. أعد رفعها من لوحة الإدارة.
- **السائقون** صاروا يدخلون بـ**الجوال + الرمز** بدل اختيار الاسم من قائمة، لأن القائمة كانت تكشف أسماء السائقين لأي زائر. السائق التجريبي `0500000000` / `1111` منقول، واحذفه قبل الإطلاق.
- **العملاء** صاروا يدخلون برمز SMS، فالرموز السرية القديمة ما تنتقل ولا تُحتاج.

## ملاحظات وحدود معروفة

- **التتبع بالخلفية:** المتصفحات توقف مشاركة الموقع إذا قفل السائق الشاشة أو طلع من التطبيق، فالسائق لازم يخلي التطبيق مفتوح أثناء التوصيل (التطبيق ينبهه). الحل الكامل تطبيق سائق أصلي (native)، وهو أول مبرر حقيقي للنزول لمتاجر التطبيقات.
- **خرائط OpenStreetMap** مجانية ومناسبة لحجم مدينة. لو كبر الاستخدام، استبدلها بـ Mapbox أو Google Maps (بسطرين في `public/js/app.js`).
- **Google Fonts** تُحمَّل من الإنترنت. لو تبي استقلالية كاملة، نزّل الخطوط وقدّمها من `public/`.
- **الطلب الخاص** دفعه كاش فقط، لأن المبلغ ما يُعرف قبل التسعير.
- **حجم التشغيل:** SQLite وخادم واحد يكفون مئات الطلبات يومياً بسهولة. لو احتجت عدة خوادم مستقبلاً، الانتقال لـ PostgreSQL محصور في `db.js` و`repo.js`.
